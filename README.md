# Cortex Labs — Homebrew tap

Native macOS developer tools from [Cortex Labs](https://getcortexlabs.com).

```sh
brew tap getcortexlabs/tap
brew install --cask marshall-mq
```

| Cask | App | What it is |
| --- | --- | --- |
| `marshall-mq` | [Marshall MQ](https://getcortexlabs.com/products/marshall/) | Kafka and RabbitMQ client that reads your queues without disturbing them. |

Every app updates itself (Sparkle); `brew upgrade` is a convenience, not a requirement.
